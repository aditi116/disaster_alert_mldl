# Application Rebranding: ResQNet

## ✅ Rebranding Complete

The application has been successfully rebranded from **"Disaster Alert Platform"** to **"ResQNet"**.

## What is ResQNet?

**ResQNet** is a portmanteau of:
- **ResQ** - Rescue/Request
- **Net** - Network

It represents a network for rescue operations, emergency requests, and resource sharing during disasters.

## Brand Identity

### Name: ResQNet
- **Pronunciation**: "Res-Q-Net" or "Rescue Net"
- **Tagline**: Real-time Emergency Platform
- **Purpose**: Crowdsourced disaster alerts and resource sharing

### Visual Elements (Current):
- **Logo Icon**: 🚨 Alert Triangle (AlertTriangle from lucide-react)
